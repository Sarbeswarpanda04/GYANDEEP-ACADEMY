# GyanDeep Academy Website

Responsive SEO-focused static website for GyanDeep Academy, Coaching Centre, Khordha, Odisha.

Features: responsive layout, logo-themed navy/gold design, Font Awesome icons, Google Fonts, light/dark mode, mobile menu, animations, Classes VI-X, subjects, learning method, admissions, WhatsApp enquiry form, FAQ, contact section, SEO meta tags, Open Graph, JSON-LD, robots.txt and sitemap.xml.

Before deployment: replace `https://YOUR-DOMAIN.com/` in `index.html`, `robots.txt` and `sitemap.xml` with the real domain. Add exact centre address, opening date, fees and batch timings when finalized. For production, Font Awesome recommends using an official Kit for current hosted usage.
